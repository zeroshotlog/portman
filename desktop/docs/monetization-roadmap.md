# Portman 収益化ロードマップ

収益化に向けたフェーズ別計画。

---

## 現在の状況

| 項目 | 状態 |
|------|------|
| ソースコード | 非公開（Private リポジトリ） |
| ライセンス | Proprietary EULA |
| 配布形態 | GitHub Releases（バイナリのみ） |
| 価格 | 無料（Beta） |
| 署名 | なし（Gatekeeper警告あり） |

---

## Phase 1: 無料β配布（現在）

**目的:** 市場検証、ユーザーフィードバック収集

### やること

- [x] Proprietary EULA を設定
- [x] ランディングページ作成
- [x] VitePress ドキュメント作成
- [ ] 公開リポジトリ作成（zeroshotlog/portman）
- [ ] GitHub Releases で DMG 配布
- [ ] ランディングページ + Docs を GitHub Pages にデプロイ

### 配布物

| 項目 | 公開先 |
|------|--------|
| DMG（未署名） | GitHub Releases |
| ランディングページ | GitHub Pages |
| ドキュメント | GitHub Pages |
| MCP サーバー | npm (portman-mcp) |

### ユーザーへの案内

- 無料で利用可能（Beta期間中）
- 署名なしのため初回起動時に右クリック→開く が必要
- フィードバックは GitHub Issues で受付

---

## Phase 2: 有料化準備

**目的:** 有料販売に耐えるUX・信頼性の確立

### 前提条件

- ある程度のユーザー数・フィードバックを獲得
- 製品として安定した状態

### やること

- [ ] Apple Developer Program 登録（$99/年）
- [ ] Developer ID 署名の設定
- [ ] Notarization（公証）の設定
- [ ] GitHub Actions で署名付きビルド自動化
- [ ] ライセンス認証機能の実装検討

### Apple Developer Program で得られるもの

| 項目 | 効果 |
|------|------|
| Developer ID 署名 | Gatekeeper警告が消える |
| Notarization | Apple公証済みの信頼性 |
| アプリ数制限 | なし |
| 公証回数制限 | なし |

### 署名後の配布

```
署名なしDMG → 署名 + 公証済みDMG
```

ユーザーは右クリック不要で通常起動可能に。

---

## Phase 3: 正式有料化

**目的:** 持続可能な収益モデルの確立

### 価格戦略（検討中）

| モデル | 説明 |
|--------|------|
| **買い切り** | 1回払い、メジャーアップデートは別料金 |
| **サブスクリプション** | 月額/年額、継続的な収益 |
| **フリーミアム** | 基本無料 + Pro機能有料 |

### フリーミアム案（例）

| 機能 | Free | Pro |
|------|------|-----|
| ポートスキャン | ○ | ○ |
| ラベル管理 | 5件まで | 無制限 |
| MCP連携 | ○ | ○ |
| 複数プロファイル | - | ○ |
| 優先サポート | - | ○ |

### ライセンス認証方式（検討中）

| 方式 | 特徴 |
|------|------|
| **オンライン認証** | サーバー必要、最も安全 |
| **オフライン認証** | ライセンスキー方式、サーバー不要 |
| **Gumroad/Paddle連携** | 決済 + ライセンス管理を外部委託 |

### 既存βユーザーへの対応

- β期間中のユーザーには優遇価格を提供
- または一定期間の無料利用権を付与

---

## リスクと対策

### 最大のリスク

> パクられることではなく、ユーザーが増えないこと

### 対策

| リスク | 対策 |
|--------|------|
| ニーズが弱い | β期間でフィードバック収集、ピボット検討 |
| 差別化不足 | MCP連携という独自価値を強化 |
| 競合出現 | 先行者優位、コミュニティ構築 |
| クラック | 価格を適正に、過度な対策は避ける |

## タイムライン目安

```
Phase 1 (現在〜)
  │  無料βリリース
  │  ユーザーフィードバック収集
  │  機能改善
  ↓
Phase 2 (ユーザー増加後)
  │  Apple Developer Program 登録
  │  署名 + 公証対応
  │  ライセンス認証実装
  ↓
Phase 3 (製品安定後)
     v1.0 正式有料リリース
```

具体的な期間は市場反応次第。焦らず、価値が認められてから有料化する。
