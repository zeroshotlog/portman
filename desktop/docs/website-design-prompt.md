# Portman ランディングページ デザイン依頼

## プロジェクト概要

macOS向けローカルポート管理ツール「Portman」のランディングページをデザインしてください。

### 添付画像
- アプリの画面のスクリーンショット（ダークモード）→ ページ内で使用
- アプリアイコン → favicon、ヘッダー、ヒーローセクションで使用

### アプリの特徴
- アクティブなポートをリアルタイムスキャン
- ポートにラベル・メモを付けて管理
- プロセス名・タイプの自動検出
- ダークモード対応
- ターゲット: 開発者（個人〜小規模チーム）

### 配布形態
- **デスクトップアプリ:** GitHub Releasesからの直接ダウンロード（DMG）
- **MCP サーバー:** npm パッケージとして配布（AIエージェント連携用）
- Free (Beta) - Proprietary EULA

## ランディングページ (index.html)

**目的:** アプリの価値を伝え、ダウンロード/インストールに誘導

**デザインパターン:** 複数のデザインパターンを提案してください（3〜5案）

**必須セクション:**

### ヒーロー
- キャッチコピー
- 添付のアプリ画面のスクリーンショットを使用
- ダウンロードボタン

### 機能紹介
3-4つの主要機能をアイコン付きで:
- ポートスキャン
- ラベル管理
- プロセス検出
- ダークモード対応

### スクリーンショット
- 添付のアプリ画面のスクリーンショット（ダークモード）を掲載

### デスクトップアプリ
- 動作環境: macOS 11.0以降、Apple Silicon
- ダウンロード: GitHub Releasesへのリンク
- SHA256検証方法

### MCP サーバー（AI連携）
AIエージェント（Claude等）と連携できるMCPサーバーとしても利用可能なことを紹介。

簡潔なインストール方法:
```bash
# Claude Code
claude mcp add portman -- npx portman-mcp

# Claude Desktop (claude_desktop_config.json)
{
  "mcpServers": {
    "portman": {
      "command": "npx",
      "args": ["portman-mcp"]
    }
  }
}
```

npm パッケージへのリンク: https://www.npmjs.com/package/portman-mcp

## デザイン要件

### トーン & スタイル
- クリーン、ミニマル、プロフェッショナル
- macOSネイティブアプリらしい洗練された印象
- 開発者ツールらしい信頼感
- コンパクトにまとめ、縦長になりすぎないレイアウト

### 禁止事項
- 人物の画像やイラストは使用しない
- ストックフォトは使用しない

### アイコン使用
- favicon: 添付のアプリアイコンを使用
- ヘッダーロゴ: アイコン + "Portman" テキスト
- ヒーローセクション: 必要に応じてアイコンを配置

### スクリーンショット使用
- 添付のアプリ画面のスクリーンショット（ダークモード）をそのままページ内に配置

### カラー
- アプリのアクセントカラー: ブルー系（#007AFF または類似）
- ダークモード対応（prefers-color-scheme）

### レスポンシブ
- デスクトップ優先（ターゲットがmacOS開発者のため）
- モバイルでも閲覧可能に

### 技術制約
- 静的HTML/CSS/JS（GitHub Pages でホスト）
- フレームワーク不要（シンプルに保つ）
- 外部依存は最小限（CDNフォント程度）
