# Active Ports

The main view shows all active port listeners on your system.

![Active Ports](/screenshot.png)

## Port List

Each row displays:

| Column | Description |
|--------|-------------|
| **Port** | The port number (click to copy) |
| **Process** | The process name using the port |
| **Type** | Auto-detected service type (node, python, postgres, etc.) |
| **Label** | Custom label you've assigned |
| **PID** | Process ID |

## Filtering

Use the filter bar to search by:
- Port number
- Process name
- Label text

## View Modes

Toggle between:
- **List View** - Detailed table format
- **Grid View** - Compact card layout

## Refresh

Click the refresh button or use the keyboard shortcut to rescan ports. Scanning typically completes in under 0.5 seconds.

## Quick Actions

Hover over a row to reveal:
- **Edit** - Modify the label
- **Delete** - Remove the label
